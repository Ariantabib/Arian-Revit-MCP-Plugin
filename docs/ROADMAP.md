# Roadmap: Arian Revit MCP Plugin

وضعیت فعلی: نسخهٔ ۱.۰ با حدود ۲۵۸ ابزار. معماری، سازه، فمیلی از صفر، متریال، وارنینگ و دیالوگ و Dynamo-Python روی Revit 2027 تست زنده شده‌اند.
ابزارهای rebar، بار سازه‌ای، الکتریکال، اکسپورت، لینک، worksets، ارور واقعی `ignore_and_resolve_errors` و نمونه‌های Dynamo روی Revit 2027 تست زنده شدند؛ باگ‌ها رفع شد و سناریوها در `scripts/scenarios` (struct3, mep4, arch5, warnpol1, fam4, dyn2) هستند. گزارش: [LIVE-TEST-REPORT.md](LIVE-TEST-REPORT.md).

## وضعیت اجرا (نسخهٔ ۱.۱.۰)

**فاز ۰ بسته شد.** همه‌چیز انجام شد، جز دو مورد که عمداً کنار گذاشته شدند:
- `execute_csharp` لغو‌شدنی نیست؛ Revit API تک‌نخی است و قطع کد در میانهٔ ترنزکشن مدل را خراب می‌کند. فراخواننده HTTP timeout می‌گیرد، ولی کد تا پایان اجرا می‌شود. این محدودیت در راهنما ثبت شده.
- اجرای خودکار بررسی‌ها در هر build به `scripts/package.ps1` منتقل شد (نیاز به سرور روشن دارد، چون لیست ابزارها از سرور می‌آید): `gen_tools_doc.mjs` و `check_knowledge.py` (با exit code).

**فاز ۱، انجام‌شده:** نسخهٔ مرکزی (`Directory.Build.props`)، `scripts/package.ps1` (zip نصب‌پذیر با Install/Uninstall بدون SDK و بدون admin، تست‌شده)، `scripts/sign.ps1`، LICENSE (MIT)، CHANGELOG، `.gitignore`، مخزن Git.
**فاز ۱، انجام‌نشده (با دلیل):**
- امضای واقعی: به گواهی Code Signing معتبر نیاز دارد (گواهی خودامضا پیام را برنمی‌دارد و اضافه‌کردنش به Trusted Publishers تنظیم امنیتی سیستم است). اسکریپت آماده است.
- Installer با Inno Setup/MSI: ابزارش نصب نیست؛ فعلاً zip + Install.cmd جایگزین است.
- چند نسخهٔ Revit: کد صدها جا از `ElementId.Value` و API نسخهٔ ۲۰۲۷ استفاده می‌کند و Revit 2025/2026 روی این سیستم نصب نیست؛ نیاز به کار جدا دارد.
- Auto-update، ویدیوها، CI: CI بدون DLL های Revit قابل build نیست.

اولویت‌ها: **P0** = لازم قبل از استفادهٔ جدی، **P1** = ارزش بالا، **P2** = تکمیلی، **P3** = آینده.

## فاز ۰: تثبیت نسخهٔ ۱.۰ (P0، ۱ تا ۲ هفته)

| کار | معیار پذیرش |
|---|---|
| تست زندهٔ ابزارهای تست‌نشده (rebar، loads، truss، electrical، spaces، export، links، worksets) | هر گروه یک سناریو در `scripts/scenarios` دارد و پاس می‌شود، یا به‌عنوان «پشتیبانی‌نشده» مستند شده است |
| سناریوی ارور واقعی برای `ignore_and_resolve_errors` | حداقل ۳ نوع ارور رایج خودکار رفع می‌شود و خروجی tool آن را گزارش می‌کند |
| اجرای کامل همهٔ سناریوها با یک دستور (`run_all.ps1`) و گزارش pass/fail | بعد از هر تغییر یک رگرسیون کامل ۱۰ دقیقه‌ای اجرا می‌شود |
| بررسی `Dynamo` روی گراف‌های نمونه | معلوم شود کدام گراف‌ها المان Revit می‌سازند و راهنما بروزرسانی شود |
| پایداری: timeout، صف درخواست‌ها، Revit مشغول، حالت بدون Document | هیچ حالتی باعث هنگ HTTP نشود؛ خطای واضح برگردد |
| `execute_csharp`: محدودیت زمان و لغو اجرا | اسکریپت بی‌نهایت سرور را قفل نکند (در حد امکان Revit) |
| پاک‌سازی: ابزارهای تکراری/اضافی، نام‌گذاری یکدست، توضیحات ابزار | `check_knowledge.py` و `gen_tools_doc.mjs` در هر build اجرا شوند |

## فاز ۱: توزیع، امضا و تجربهٔ نصب (P0 تا P1)

- امضای دیجیتال DLL (گواهی Code Signing) تا پیام «Always Load» هر بار نیاید.
- Installer واقعی (MSI یا Inno Setup): نصب، آپدیت، حذف، افزودن به Claude Desktop/Cursor.
- پشتیبانی از چند نسخهٔ Revit (2024، 2025، 2026، 2027) با multi-target و لایهٔ سازگاری API (ElementId و Forge types).
- Auto-update و نمایش نسخه در About؛ changelog.
- صفحهٔ مستندات و چند ویدیوی کوتاه (نصب، اولین پروژه، ساخت فمیلی).
- لایسنس و مخزن Git (CI: build، تحلیل‌گر، اجرای تست‌های غیر-Revit).

## فاز ۲: عمق معماری (P1)

1. **عناصر باقی‌ماندهٔ معماری:** رمپ، slab edge، wall sweep/reveal، آشیانه و دورچین سقف (fascia/gutter)، سقف‌های پیچیده (چندشیب، dormer)، شیشه‌خور و کرتن‌وال پیشرفته (panelها، mullionها، درب داخل کرتن‌وال).
2. **پله‌های پیچیده:** L، U، winder، مارپیچ با پارامترهای آیین‌نامه‌ای (ارتفاع پله و کف‌پله، عرض حداقل).
3. **فضا و مساحت:** Area scheme/Area plan (زیربنا، مفید، ناخالص)، رنگ‌بندی اتاق‌ها بر اساس کاربری، جدول برنامه فیزیکی در برابر مدل.
4. **Finish ها:** تکمیل خودکار اتاق (کف، سقف، کفپوش، سنگ‌کاری، کاغذ دیواری) از پارامترهای Room.
5. **سایت:** toposurface از نقاط/منحنی تراز، subregion، building pad، جاده و پارکینگ، sun path و سایه.
6. **Design Options و Phasing:** مدیریت گزینه‌ها؛ برای Phase نبودن API، ابزار راهنما و مسیر UI Automation برای ساخت Phase جدید.
7. **ورودی‌های تصویر/DWG:** import پلان DWG و تبدیل خودکار به دیوار/اتاق (تشخیص لایه‌ها)، trace از تصویر.
8. **Detail و Legend:** کتابخانهٔ جزئیات تیپ (detail components)، legend، revision cloud هوشمند.
9. **ابزارهای تولید خودکار:** تولید پلان از برنامه فیزیکی با چیدمان بهینه (فراتر از مستطیل)، نما و رمپ دسترسی معلولین، تبدیل mass به طبقات (floor by face).

## فاز ۳: عمق سازه (P1)

1. **Rebar کامل:** تیر، دال، فونداسیون، دیوار برشی؛ خاموت و قلاب؛ rebar cover؛ جداول میلگرد؛ ابزار تولید آرماتور بر اساس نتایج طراحی.
2. **مدل تحلیلی:** خواندن/ویرایش Analytical Model، ترکیب بارها، load cases، export به ETABS/SAP/Robot (IFC/Analytical link).
3. **فولاد:** اتصالات (Steel Connections API)، ورق‌ها، پیچ و مهره، ترازبندی و shop drawing ساده.
4. **پیش‌ساخته و پس‌تنیده:** assembly، part، parts-based layout.
5. **ابزارهای هماهنگی:** تطبیق ستون‌ها با دیوار، تیر و سقف کاذب، اعتبارسنجی خودکار ارتفاع آزاد.
6. **پیش‌طراحی سازه:** برآورد مقطع از بار و دهانه (با آیین‌نامهٔ ایرانی مبحث ۶ و ۹ و ۱۰ و استانداردهای ACI/AISC به‌عنوان پارامتر).

## فاز ۴: عمق MEP (P1)

1. **Routing هوشمند:** مسیریابی خودکار داکت/لوله/سینی کابل با الگوریتم A* و پرهیز از برخورد، ارتفاع‌های استاندارد، شیب تخلیه.
2. **محاسبات:** سایز داکت و لوله از دبی/سرعت، افت فشار، بار گرمایی و سرمایی (از Spaceها)، تعداد دیفیوزر.
3. **الکتریکال:** پنل‌ها، جدول پنل، ظرفیت مدار، روشنایی بر اساس لوکس، پریز و سوئیچ بر اساس نوع فضا، سیم‌کشی.
4. **لوله‌کشی:** fixture units، سایزینگ فاضلاب، آبرسانی، اطفای حریق (اسپرینکلر با پوشش).
5. **تجهیزات و کتابخانه:** تولید فمیلی تجهیزات رایج (AHU، فن‌کوئل، پمپ، پنل، چراغ، دیفیوزر) با connector درست.
6. **QA:** open connectors، disconnected systems، pressure drop، clash، گزارش وضعیت سیستم‌ها.
7. **Fabrication Parts و hanger/support** (P3).

## فاز ۵: فمیلی (P1)

- توسعهٔ `family_build_from_spec`: قوس و منحنی، چند پروفایل، nested families، آرایه‌های پارامتریک، visibility rules پیشرفته، پارامتر شرطی (`if`)، lookup tables.
- کتابخانهٔ آماده: در/پنجره (با باز شدن و گردش)، مبلمان رایج، سرویس بهداشتی، آشپزخانه، چراغ، دیفیوزر، ستون و تیر استاندارد، فونداسیون، مصالح نما.
- Adaptive components و pattern-based families (نماهای پارامتریک).
- QA خودکار فمیلی: flex test عمیق، چک نام‌گذاری، پارامتر شرح، حجم فایل، subcategory و detail levels.
- کاتالوگ type (type catalog TXT)، shared parameters، Family Types از Excel.
- ورود فمیلی از Autodesk Cloud/Manufacturer (در صورت پشتیبانی API).

## فاز ۶: متریال و تصویرسازی (P2)

- Physical/Thermal assets (بتن، فولاد، عایق) و انتساب به پارامترهای تحلیلی.
- کتابخانهٔ متریال ایرانی و جهانی (آجر، سنگ، سرامیک، گچ، رنگ) با رنگ و پترن درست.
- Texture و بافت (Bump، Reflection) و تنظیم render appearance.
- ارتباط با Twinmotion و Enscape (در صورت نصب): ارسال view، تنظیم مقیاس، خروجی تصویر و ویدیو.
- ابزار اتوماتیک «material pass»: انتساب متریال به همهٔ typeها بر اساس نام یا کد.

## فاز ۷: مستندسازی و استانداردها (P1)

1. **View templates:** ساخت و ویرایش، فیلترها، کنترل گرافیک (Visibility/Graphic Overrides) کامل.
2. **شیت اتوماتیک:** چیدمان هوشمند viewport ها، title block، شماره‌گذاری، ایندکس شیت، revision.
3. **ابعاد و تگ هوشمند:** جلوگیری از همپوشانی، ابعاد خودکار پلان (دیوار، درب، پنجره، محور).
4. **جدول‌های پیشرفته:** formulas، calculated values، conditional formatting، export به Excel (CSV و XLSX).
5. **فارسی و RTL:** متن فارسی در Text Note و تگ، شماره‌گذاری فارسی، تاریخ شمسی در title block.
6. **استانداردهای ایرانی:** مبحث ۴ (الزامات عمومی)، ۱۹ (صرفه‌جویی انرژی)، ۲۲ و ... به‌عنوان قوانین قابل‌چک.
7. **CAD/PDF:** تنظیم export DWG با لایه‌بندی استاندارد، PDF تک‌فایل و مجموعه‌ای.

## فاز ۸: لایهٔ هوشمند و کنترل کیفیت (P1 تا P2)

- **Rule engine** برای بررسی مدل: ضوابط ارتفاع، عرض راه‌پله، دسترسی، ایمنی حریق، تراکم، نورگیری. گزارش به‌صورت JSON و صفحهٔ HTML.
- **Brief → Program → Plan:** تبدیل متن به برنامه فیزیکی، چیدمان، مدل، مستندات و گزارش مساحت.
- **Vision:** بررسی عکس نما/پلان و مقایسه با مدل (ورودی تصویر ایجنت)، تبدیل اسکچ به پلان.
- **5D و 4D:** برآورد متره و هزینه از `get_quantities` و فهرست‌بها، برنامه‌ریزی زمانی (Phasing/Timeliner).
- **IFC و BCF:** round trip، issue ها، نمایش clash در Navisworks/BCF.
- **Energy و تحلیل:** ارسال به Insight/EnergyPlus در صورت امکان، sun study.
- **Multi-agent:** الگوهای هماهنگی (معمار، سازه، تأسیسات) با پرامپت‌های آماده و Checklist.

## فاز ۹: پلتفرم، امنیت و MCP (P1)

1. **MCP پیشرفته:** progress notifications و SSE برای عملیات طولانی، منابع زنده (`revit://model/...`)، ابزار بازیابی زمینه (tool search برای مدل‌های کم‌context)، elicitation.
2. **ایمنی تغییرات:** حالت Preview/Dry-run، Undo گروهی برای هر درخواست ایجنت، لاگ ممیزی (audit)، snapshot قبل از عملیات بزرگ.
3. **سطح دسترسی:** allow/deny بر اساس category ابزار و بر اساس نوع کلاینت، قفل ابزارهای مخرب، تأیید انسانی برای `delete_*` و `purge_unused`.
4. **امنیت:** توکن پیش‌فرض، HTTPS محلی، محدودسازی `execute_csharp` (sandbox یا allow-list)، امضای ابزارهای سفارشی.
5. **دسترسی از راه دور:** tunnel امن با احراز هویت (OAuth) برای استفاده از ایجنت‌های ابری؛ مدیریت rate limit.
6. **Worksharing:** هماهنگی با central، ownership، sync امن، رفع conflict.
7. **ACC/BIM 360:** باز کردن/ذخیره مدل ابری، issues.
8. **Telemetry اختیاری:** آمار اجرای ابزارها و خطاها (با رضایت کاربر) برای بهبود کیفیت.
9. **پایداری حافظه:** مدیریت ALC، cache ها، بازگشایی خودکار بعد از crash.

## فاز ۱۰: UI و تجربهٔ کاربر (P2)

- پنل داخل Revit: وضعیت سرور، لاگ زندهٔ فراخوانی ابزارها، دکمهٔ Undo آخرین عملیات ایجنت، تاریخچهٔ تصاویر.
- تنظیمات پیشرفته (ابزارهای فعال، سیاست هر دسته، پروفایل‌ها: «Phase 1»، «Phase 2»، «MEP»).
- نمایش پیشرفت عملیات طولانی و دکمهٔ لغو.
- فارسی‌سازی UI و آیکون‌های حرفه‌ای.

## ترتیب پیشنهادی اجرا

1. فاز ۰ (تثبیت) و فاز ۱ (امضا و installer): پایه برای هر استفادهٔ واقعی.
2. فاز ۳ و ۴ به‌صورت موازی با فاز ۲، چون معماری و سازه و MEP همزمان توسط ایجنت‌ها مصرف می‌شوند.
3. فاز ۷ بعد از معماری؛ بدون مستندات، مدل برای تحویل ناقص است.
4. فاز ۹ (ایمنی و MCP پیشرفته) قبل از اینکه ایجنت‌ها روی پروژه‌های واقعی کار کنند.
5. فاز ۵ و ۸ به‌صورت مداوم در طول پروژه رشد می‌کنند.

## ریسک‌ها

| ریسک | مقابله |
|---|---|
| محدودیت‌های Revit API (Phase، View Template، برخی ابزارهای UI-only) | ابزار راهنما + UI Automation امن + اسکریپت `execute_csharp` |
| تغییر API بین نسخه‌های Revit | لایهٔ سازگاری و تست روی هر نسخه |
| خطا در مدل‌های بزرگ (کندی، timeouts) | batching، تراکنش‌های کوچک، progress و لغو |
| ایجنت‌های اشتباه‌کار | dry-run، گروه Undo، لاگ ممیزی |
| امنیت `execute_csharp` | تنظیم پیش‌فرض ایمن‌تر برای محیط‌های سازمانی |
| کیفیت خروجی وابسته به مدل زبانی | knowledge base، اعتبارسنجی خودکار، بازخورد تصویری |

## تعریف «تمام شد» برای نسخهٔ ۲.۰

- همهٔ ابزارها تست زنده شده‌اند و رگرسیون خودکار دارند.
- نصب با installer و امضا شده است؛ بدون پیام Always Load.
- یک ایجنت می‌تواند بدون دخالت، یک ساختمان مسکونی ۴ طبقه را در ۳ فاز مدل کند: معماری، سازه، تأسیسات، با شیت و جدول، و گزارش بررسی خودکار.
- مستندات فارسی و انگلیسی کامل و چند نمونهٔ پروژهٔ آماده.

### وضعیت فاز ۲ (نسخهٔ ۱.۲.۰)
انجام‌شده و تست زنده: رمپ، slab edge، fascia، gutter، wall sweep/reveal، پلهٔ L و U با پاگرد خودکار، Area plan از Roomها، finish اتاق، subregion سایت، لایه‌های DWG و تبدیل به دیوار.
باقی‌مانده (فاز بعد): پلهٔ winder/مارپیچ، dormer و سقف چندشیب پیچیده، پنل/مولیون سفارشی کرتن‌وال، Design Options، detail/legend، mass→floor.

### وضعیت فاز ۳ (نسخهٔ ۱.۳.۰)
انجام‌شده و تست زنده: آرماتوربندی تیر (طولی + خاموت با ناحیهٔ متراکم)، دال/فونداسیون (مش دولایه)، دیوار برشی (دو پرده)، cover، ترکیب بار، پیش‌طراحی مقاطع، کنترل ارتفاع آزاد و هم‌راستایی ستون‌ها.
باقی‌مانده: اتصالات فولادی، assembly/پس‌تنیدگی، export تحلیلی به ETABS/SAP، جدول میلگرد (create_schedule روی Structural Rebar)، قلاب و خم خاموت.

### وضعیت فاز ۴ (نسخهٔ ۱.۴.۰)
انجام‌شده و تست زنده: سایزینگ داکت و لوله (دبی/fixture unit)، بار سرمایی/گرمایی و تعداد دیفیوزر از Space، تغییر سایز خودکار داکت، لولهٔ شیب‌دار، مسیریابی خودکار بدون برخورد، چیدمان روشنایی با لوکس، اسپرینکلر، پریز، بار تابلو و panel schedule، گزارش QA و clash.
باقی‌مانده: A* سه‌بعدی کامل با عبور از دیوار/سقف، افت فشار کل شبکه، سایزینگ فاضلاب، سینی کابل خودکار، تولید فمیلی تجهیزات، hanger و Fabrication.

### وضعیت فازهای ۵، ۶، ۷ و ۱۰ (نسخهٔ ۱.۵.۰)
