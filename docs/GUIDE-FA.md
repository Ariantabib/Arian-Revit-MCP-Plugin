# راهنمای Arian Revit MCP Plugin (فارسی)

این پلاگین یک **سرور MCP** داخل Revit 2027 است. هر ایجنت هوش مصنوعی (Claude، GPT، Gemini، Cursor …) بعد از اتصال می‌تواند
در رویت **مدل‌سازی کند، ویرایش کند، مستندسازی کند، فمیلی از صفر بسازد، متریال بسازد، وارنینگ‌ها را نادیده بگیرد** و حتی کد C# / Dynamo اجرا کند.
همهٔ ابعاد در API به **میلی‌متر** و زاویه‌ها به **درجه** هستند.

## ۱) نصب
```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```
بار اول رویت دربارهٔ «افزونهٔ امضا نشده» سؤال می‌کند → **Always Load** را بزنید.

## ۲) روشن کردن سرور
رویت را باز کنید → تب **Arian** → دکمهٔ **Start Server**.
دکمه قرمز می‌شود و آدرس `http://127.0.0.1:8765/mcp` فعال است. برای خاموش کردن دوباره بزنید (Stop Server).

دکمه‌های دیگر:
- **Connect Agent**: دستورهای آمادهٔ اتصال (Claude Code / Claude Desktop / Cursor) + دکمهٔ «Add to Claude Desktop config».
- **Settings**: پورت، استارت خودکار با رویت، توکن، خاموش/روشن کردن اجرای کد، سیاست وارنینگ، دسته‌بندی ابزارها.
- **Warnings**: حالت‌های «پیش‌فرض → نادیده گرفتن وارنینگ → نادیده گرفتن + رفع خودکار ارورها».
- **Auto Dialogs**: پاسخ خودکار به پنجره‌های سؤال رویت (با کم‌خطرترین گزینه).
- **Dismiss Dialogs**: بستن پنجره‌های باز (حتی وقتی رویت قفل است).
- **Run Dynamo Graph**: اجرای فایل .dyn.

## ۳) اتصال به ایجنت
**Claude Code**
```bash
claude mcp add --transport http arian-revit http://127.0.0.1:8765/mcp
```
**Claude Desktop**: در پنجرهٔ Connect Agent دکمهٔ «Add to Claude Desktop config» را بزنید و Claude Desktop را ری‌استارت کنید (Node.js لازم است).

## ۴) نمونه دستورها به ایجنت
- «یک پروژهٔ جدید بساز؛ ساختمان ۳ طبقهٔ اداری ۲۴×۱۶ متر با گرید ۶ متری، اسکلت بتنی، نمای شیشه‌ای جنوبی، هسته با پله، و جدول مساحت بده.»
- «فمیلی میز ناهارخوری پارامتریک (Width/Depth/Height) با ۳ تایپ بساز و در پروژه بگذار.»
- «پروژه را به فاز ۲ ببر: متریال و لایه‌های واقعی دیوار و سقف، جدول درب و پنجره، شیت‌ها.»
- «سیستم تهویه را مسیرکشی کن و برخوردها را با سازه بررسی کن.»
- «همهٔ وارنینگ‌ها را گزارش کن و موارد امن را رفع کن.»

ایجنت به‌طور خودکار «دفترچهٔ راهنما» (workflow، LOD، معماری، سازه، تأسیسات، فمیلی) را از سرور می‌گیرد و بعد از هر مرحله با `get_view_image` **تصویر مدل را می‌بیند** تا خطاها را اصلاح کند.

## ۵) فازهای پروژه
- **فاز ۱ (طرح اولیه)** ≈ LOD 100–200: توده، پلان‌ها، نماها، برش‌ها، مساحت فضاها.
- **فاز ۲ (طرح تفصیلی)** ≈ LOD 300: جزئیات دیوار/سقف با لایه و متریال، سازه هماهنگ، درب/پنجره، پله و نرده، سقف کاذب، مبلمان، تأسیسات اصلی، شیت و جدول‌ها.
پرامپت‌های آماده: `start_architectural_project`، `phase2_design_development`، `model_structure`، `mep_design`، `create_family`، `produce_drawing_set`، `model_audit`.

## ۶) وارنینگ و ارور
- حالت **Ignore warnings** وارنینگ‌ها را در لحظهٔ ایجاد حذف می‌کند (مثل «OK/Ignore»).
- حالت **Ignore + auto-resolve** برای ارورها نیز راه‌حل پیش‌فرض رویت را اعمال می‌کند.
- اگر پنجره‌ای باز ماند: ابزارهای `get_dialog_log` و `dismiss_dialogs` یا دکمهٔ Dismiss Dialogs.
- آخرین راه: ایجنت Computer-use روی دکمه کلیک کند.

## ۷) امنیت
فقط `127.0.0.1`؛ بدون دسترسی از مرورگر/سایت‌ها؛ توکن اختیاری؛ همهٔ تغییرات با **Ctrl+Z** قابل بازگشت‌اند.
اجرای کد (`execute_csharp`) با دسترسی کامل شماست؛ فقط به ایجنت مورد اعتماد وصل کنید یا در Settings خاموشش کنید.

- `scripts\hot.ps1`: بیلد ابزارها و جایگزینی داغ بدون ری‌استارت رویت.
